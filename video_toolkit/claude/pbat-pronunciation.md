PBAT (as in "PBAT Door to Door Movement", "PBAT Cares") is pronounced "P-Bat", not letter by letter "P B A T".

**Why:** The user corrected this on the Nigerian healthcare campaign video (2026-11-17) and asked for it to apply to all their videos.

**How to apply:** Whenever generating or checking TTS/voiceover text, write it phonetically as "Pee-Bat" (e.g. "the Pee-Bat Door to Door Movement") so the voice says it as one word. Keep on-screen text as "PBAT". When a voiceover comes from someone else's recording (e.g. voice-changed), flag any spoken PBAT so the user can check it.
